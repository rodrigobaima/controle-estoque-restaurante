# 🍽️ Sistema de Controle de Estoque para Restaurante

## 📖 Sobre o projeto

Este projeto tem como objetivo desenvolver um **Sistema de Controle de Estoque para Restaurante** utilizando tecnologias amplamente utilizadas no mercado.

Mais importante do que terminar o sistema é **aprender a trabalhar em equipe**, utilizar Git/GitHub corretamente e desenvolver boas práticas de programação.

---

# 👥 Equipe

Cada integrante terá responsabilidades, mas todos poderão aprender e contribuir em todas as áreas do projeto.

## Tech Lead

Responsável por:

* Organizar o projeto
* Definir a arquitetura
* Distribuir as tarefas
* Revisar Pull Requests
* Auxiliar os demais integrantes
* Garantir a qualidade do código

---

## Desenvolvedores

Responsáveis por:

* Desenvolver funcionalidades
* Corrigir bugs
* Criar telas
* Implementar regras de negócio
* Fazer testes
* Atualizar a documentação quando necessário

# 🌳 Organização das Branches

Nunca desenvolver diretamente na **main**.

Fluxo de trabalho:

main

↓

develop

↓

feature/nome-da-funcionalidade

Exemplos:

* feature/login
* feature/produtos
* feature/dashboard
* feature/estoque

---

# 🔀 Fluxo de Trabalho

1. Atualizar a branch `develop`.
2. Criar uma nova branch para a funcionalidade.
3. Desenvolver a funcionalidade.
4. Fazer commit.
5. Enviar para o GitHub.
6. Abrir um Pull Request.
7. Aguardar revisão.
8. Após aprovação, realizar o merge.

---

# 📝 Padrão de Commits

Utilizar commits descritivos.

Exemplos:

```text
feat: cria cadastro de produtos

fix: corrige cálculo do estoque

refactor: reorganiza estrutura das views

docs: atualiza README
```

---

# 📌 Regras da Equipe

* Nunca enviar código diretamente para a **main**.
* Sempre testar antes de enviar.
* Manter o código organizado.
* Fazer commits pequenos e objetivos.
* Avisar quando iniciar uma funcionalidade para evitar conflitos.
* Em caso de dúvida, perguntar antes de implementar.

---

# 🎯 Objetivo Final

Ao concluir este projeto, todos os integrantes deverão ser capazes de:

* Trabalhar com Git e GitHub.
* Desenvolver aplicações utilizando Django.
* Criar bancos de dados relacionais.
* Trabalhar em equipe.
* Utilizar boas práticas de programação.
* Desenvolver um sistema completo do início ao fim.

O objetivo principal é evoluir como desenvolvedores durante a construção deste projeto.
